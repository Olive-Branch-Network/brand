# Olive Branch Network brand files

Official logo files for Olive Branch Network (OBN).

| File | Format | Use |
|---|---|---|
| [obn-logo-32.svg](obn-logo-32.svg) | SVG, 32 × 32 | Block explorers, token lists, small icons |
| [obn-logo-256.png](obn-logo-256.png) | PNG, 256 × 256, transparent background | Listings, wallets, articles |
| [obn-app-icon-1024.png](obn-app-icon-1024.png) | PNG, 1024 × 1024, square with green background | App icons, large previews |

## Linking to a file

Each file is served at:

```
https://assets.olivebranch.network/<file name>
```

File names are permanent. If the logo changes, the files are replaced in place, so existing links keep working.
